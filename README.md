# My Land Tours & Travel — Website Project

![My Land Tours & Travel](your-logo.png)

A fully hand-coded, responsive tourism website built for **My Land Tours & Travel**, a Kenya-based safari and travel company.

This project demonstrates my practical web development skills across **HTML, CSS, JavaScript, responsive design, UI/UX, SEO, forms, and website deployment**.

🌐 **Live Website:** https://mylandtours.co.ke

---

## 📌 Project Overview

My Land Tours & Travel is a real-world commercial website designed to present the company's safari and travel services, destinations, team, partners, and booking process in a professional and accessible way.

The website was designed and developed from scratch using core web technologies rather than a website builder or pre-made template.

The goal was to create a website that is:

* Professional and trustworthy
* Responsive across desktop and mobile devices
* Easy for visitors to navigate
* Optimized for search engines
* Simple for customers to make inquiries and bookings
* Visually aligned with the company's brand

---

## 🛠️ Technologies Used

* **HTML5** — semantic page structure and content
* **CSS3** — responsive layouts, styling, animations, and visual design
* **JavaScript** — interactive components and client-side functionality
* **FormSubmit** — booking and inquiry form processing
* **Cloudflare Pages** — website hosting and deployment
* **Google Search Console** — search indexing and SEO monitoring
* **Google Business Profile** — local business presence

## ✨ Key Features

### Responsive Design

Designed to provide a consistent experience across:

* 📱 Mobile
* 💻 Desktop
* 📟 Tablet

### 🧭 Multi-Page Website

The project includes dedicated pages for:

* Home
* About
* Team
* Partners
* Booking / inquiry confirmation

### 🦁 Safari & Destination Presentation

Travel destinations and safari experiences are presented through structured sections designed to help visitors quickly understand the available experiences.

### 📩 Booking & Inquiry System

The website includes customer inquiry and package-booking forms with:

* Customer details
* Travel dates
* Number of travelers
* Vehicle preferences
* Budget information
* Additional requests
* Selected package information

Form submissions are processed through FormSubmit.

### 🔎 SEO Implementation

The project includes practical SEO elements such as:

* Page-specific titles
* Meta descriptions
* Sitemap
* Robots.txt
* Semantic HTML
* Structured page hierarchy
* Favicon and web manifest
* Search Console integration

### 📱 User Experience

The interface was designed around straightforward navigation and clear calls to action so visitors can move from:

**Discover → Explore → Choose → Inquire**

without unnecessary friction.
